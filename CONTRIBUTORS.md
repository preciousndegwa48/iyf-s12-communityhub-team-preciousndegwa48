3. Team Collaboration

The CommunityHub project follows a collaborative development workflow.

Each contributor:
- Works on an assigned Git feature branch.
- Develops and tests assigned components.
- Commits changes with meaningful commit messages.
- Pushes changes to the shared GitHub repository.
- Creates Pull Requests for code review.
- Reviews and approves contributions from other team members.
- Merges approved changes into the main branch.
